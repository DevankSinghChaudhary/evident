# Sign in With ChatGPT

As the name suggest SIWC, short for Sign in With ChatGPT, means using your
official OpenAI account to get access of model catalog that otherwise you get
on web version of ChatGPT.

!!! note "About SIWC"

    This is not some unofficial work-around browser version to get ChatGPT access
    from that but instead official OpenAI way. To understand it better refer to 
    [SIWC Documentation](https://developers.openai.com/siwc).
