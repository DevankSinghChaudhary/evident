# Introduction  

Evident is research engine built for AI and agents. It's specifically built for [vpipeline](https://www.github.com/devanksinghchaudhary/vpipeline). Built as decouplable engine that can be used standalone without needing fully pipeline.  
  
## Highlights  

- Standalone research engine.
- Input: Research Topic.
- Multiple output formats: pdf, json, yaml etc.
- Could be coupled with vpipeline for further use.
